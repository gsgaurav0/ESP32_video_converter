LIBRARIES

In Arduino IDE: Tools → Manage Libraries, install Adafruit SSD1306 and Adafruit GFX Library.

WHERE THE CODE GOES

  1. Create a new sketch, e.g. oled_video.
  2. Paste the Main.ino tab content into the main sketch file (the one that opens by default, matching your sketch folder name).
  3. Click the small dropdown arrow (top-right of the editor) → New Tab → name it exactly VideoFrame.h → paste the VideoFrame.h tab content there.
  4. Select your board: Tools → Board → ESP32 Dev Module, pick the correct COM port, then Upload.
ESP32 has plenty of flash (usually 4MB+), so it comfortably handles longer or higher-res clips. Wire.setClock(800000) in the generated code is safe on ESP32.

LIBRARIES

Same as ESP32: install Adafruit SSD1306 and Adafruit GFX Library from the Library Manager.

WHERE THE CODE GOES

  1. Same as ESP32 — paste Main.ino into the main sketch file, add a new tab named VideoFrame.h for the frame array.
  2. Tools → Board → Arduino Uno, select the port, then Upload.
Flash is tight on Uno — only 32KB total. A single 128×64 frame is 1024 bytes, so you'll fit roughly ~28 frames at most before it won't compile. Use the 96×16 or 128×32 resolution preset and a low frame count (short trim range, low FPS) to fit more animation in.
Also change Wire.setClock(800000) to Wire.setClock(400000) in Main.ino — the Uno's I2C hardware isn't rated for 800kHz.

INSTALL LIBRARIES

pip install luma.oled pillow

WHERE THE CODE GOES

  1. Download the video_oled.py tab — it already has your frame data embedded, no separate file needed.
  2. Copy it to the Pi (e.g. via scp or a USB stick), save it anywhere, e.g. ~/video_oled.py.
  3. Run it: python3 video_oled.py. Ctrl+C to stop.
Unlike the Arduino boards, the Pi runs this as a normal Python script — no compiling or flashing. If your OLED uses the SH1106 driver instead of SSD1306, change from luma.oled.device import ssd1306 to sh1106 near the top of the script.
